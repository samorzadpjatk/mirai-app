ci: harden workflows with persist-credentials and fix supabase test deps

## Summary

This PR applies security best-practices to all GitHub Actions workflows and fixes a broken test dependency.

## Changes

### Security: persist-credentials=false

Applied `actions/checkout@v6` with `persist-credentials: false` across all workflows to prevent accidental credential leakage to third-party actions:

- `.github/workflows/ci.yml`
- `.github/workflows/android-release.yml`
- `.github/workflows/ios-release.yml`
- `.github/workflows/docker-publish.yml`
- `.github/workflows/monorepo-tagging.yml`

### CI: fix git fetch authentication

With `persist-credentials: false`, the "Fetch base branch for turbo --affected" step now explicitly configures the origin URL with `GITHUB_TOKEN` before fetching.

### Cache key improvements

CI cache keys now include `github.event_name` to avoid cross-contamination between `push` and `pull_request` caches.

### fix(supabase): add missing @testing-library/dom

- Added `@testing-library/dom@^10.4.0` to `packages/supabase/package.json` devDependencies
- Updated `bun.lock`

### Verification

- [x] All 49 tests in `@mirai-app/supabase` pass locally
- [x] The previously failing `react.test.tsx` suite now passes (17/17 tests)
