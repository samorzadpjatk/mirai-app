Use CDN-based PDF.js viewer on /map; remove pdfjs-dist and webpack tooling.

Key Features:
- Interactive PDF viewer on /map (zoom via wheel/pinch, pan via drag/touch)
- Responsive layout for desktop and mobile
- Prevents page scroll while interacting with the PDF
- Clear loading and error states when the file is missing/corrupt

Technical Changes (most important):
- New client component: src/components/map/PDFViewer.tsx
- PDF.js loaded as ESM from CDN at runtime (no bundler import, no local package)
- Web Worker USED: module worker runs off the main thread, sourced from CDN
  - Worker URL: pdf.worker.min.mjs on unpkg, no local copy required
  - Keeps UI responsive while rendering PDFs
- Removed pdfjs-dist dependency and all webpack tooling (scripts/devDeps)

Worker Notes:
- PDF.js needs a separate worker (ESM: pdf.worker.min.mjs)
- Currently served from CDN; can be self-hosted later if desired

Usage:
- Default demo file: /public/dummy.pdf (replace as needed)
- Navigate to /map to test zoom, pan, and touch gestures

Verification:
- pnpm install
- pnpm dev → open /map; first page renders; zoom/pan/pinch work as expected
