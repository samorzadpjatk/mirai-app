Adds interactive PDF Map Viewer on /map and modernizes PDF.js/worker setup.

Key Features:
- Interactive PDF viewer on /map (zoom via wheel/pinch, pan via drag/touch)
- Responsive layout tuned for desktop and mobile
- Prevents page scrolling while interacting with the PDF (focus stays in viewer)
- Clear loading and error states when file is missing or corrupt

Technical Changes:
- New component: src/components/map/PDFViewer.tsx (client component)
- Uses pdfjs-dist with getDocument and GlobalWorkerOptions
- Worker configured as module worker via CDN (unpkg) with fallback to workerSrc
- Removed deprecated pdfjs-dist/webpack entrypoint
- Added basic webpack scripts (webpack:dev, webpack:build) and dev deps

Worker Notes:
- PDF.js requires a separate worker (ESM: pdf.worker.min.mjs)
- Served via CDN to avoid bundler subpath resolution issues; can be self-hosted later

Usage:
- Default demo file: /public/dummy.pdf (replace as needed)
- Navigate to /map to test zoom, pan, and touch gestures

Verification:
- pnpm install
- pnpm dev → open /map, first page renders; zoom/pan/pinch work as expected
