## Dependencies Between Files

### Drizzle Type Safety Cluster
The ORPC routers in `packages/orpc/src/api/routers/` share a common pattern of using `any` for Drizzle query builders. Fixing one router (e.g., `trip/queries.ts`) establishes a pattern that can be replicated across:
- `group/mutations.ts`
- `reward/mutations.ts`
- `challengeSubmission/mutations.ts`
- `challengeVote/mutations.ts`
- `location/mutations.ts`
- `location/queries.ts`

**Recommendation:** Extract a typed helper for Drizzle query builder callbacks.

### Test Utility Cluster
`packages/shared/src/test-utils/mock-factories.ts` provides mocks used across:
- `packages/orpc/src/api/__tests__/`
- `packages/supabase/src/__tests__/`

Fixing mock types here propagates type safety improvements to all dependent tests.

### Native App Test Cluster
MSW test files in `apps/native/src/hooks/__tests__/admin/` share patterns of:
- `.catch(() => {})` for suppressing unhandled promise rejections
- `!` non-null assertions on query data

Fixing the test helper utilities can reduce these patterns systematically.
