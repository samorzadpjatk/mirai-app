# 📱 PWA & Web Notifications - Bank Monet

## 🌟 Overview

The Bank Monet application features a complete Progressive Web App (PWA) implementation with advanced web push notifications system. Users can install the app on their devices and receive real-time notifications about group coin updates and scheduled ranking updates.

## 🚀 Features

### 📲 Progressive Web App (PWA)
- **Installable**: Can be installed on desktop and mobile devices
- **Offline Support**: Basic functionality works without internet connection
- **App-like Experience**: Full-screen mode, custom splash screen, app icons
- **Cross-platform**: Works on iOS, Android, Windows, macOS, Linux

### 🔔 Web Push Notifications
- **Real-time Notifications**: Instant alerts when coins are added/removed
- **Scheduled Notifications**: Automated ranking updates at specified times
- **Personalized Messages**: Different content based on group position
- **User Control**: Enable/disable notifications from dashboard

## 📊 Notification Types

### 1. **Immediate Notifications** ⚡
Triggered instantly when admins perform actions:

- **💰 Coin Addition**: "Wasza gildia otrzymała X monet!"
- **💸 Coin Removal**: "Wasza gildia straciła X monet!"

### 2. **Scheduled Notifications** ⏰
Automated messages sent at configured times:

- **🏆 Ranking Updates**: Personalized position and coin count
- **📈 Weekly Summaries**: Performance overview and statistics

## 🛠️ Technical Implementation

### PWA Configuration
```javascript
// next.config.js
const withPWA = require("next-pwa")({
  dest: "public",
  register: true,
  skipWaiting: true,
  disable: process.env.NODE_ENV === "development"
});
```

### Service Worker
- **Production**: Auto-generated by next-pwa
- **Development**: Custom lightweight service worker (`sw-dev.js`)
- **Push Handler**: Processes and displays notifications
- **Background Sync**: Handles offline scenarios

### Database Schema
```sql
-- Push Subscriptions
model PushSubscription {
  id        String   @id @default(cuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  endpoint  String
  p256dh    String   -- Encryption key
  auth      String   -- Authentication secret
  createdAt DateTime @default(now())
}

-- Notification Schedules
model NotificationSchedule {
  id          String   @id @default(cuid())
  name        String   -- "Daily Ranking Update"
  description String?
  startDate   DateTime
  endDate     DateTime
  hour        Int      -- 0-23
  minute      Int      -- 0-59
  isActive    Boolean  @default(true)
  lastRun     DateTime?
  createdBy   String
  admin       User     @relation(fields: [createdBy], references: [id])
}
```

## 🎯 User Journey

### 1. **Enable Notifications**
1. User visits dashboard
2. Clicks "Włącz powiadomienia" button
3. Browser prompts for permission
4. Subscription is saved to database

### 2. **Receive Immediate Notifications**
1. Admin adds/removes coins from group
2. System automatically sends notifications to all group members
3. Users receive push notification even when app is closed

### 3. **Scheduled Notifications**
1. Admin creates notification schedule in `/admin/schedules`
2. System runs at specified times
3. Fetches current ranking from database
4. Sends personalized messages to each group

## 🔧 Setup & Configuration

### Environment Variables
```bash
# VAPID Keys for Web Push (generate with: npx web-push generate-vapid-keys)
VAPID_PUBLIC_KEY="your_public_key"
VAPID_PRIVATE_KEY="your_private_key"
VAPID_EMAIL="your_email@domain.com"

# For scheduled notifications (optional)
SCHEDULER_API_KEY="your_secure_api_key"

# Public VAPID key for client-side
NEXT_PUBLIC_VAPID_PUBLIC_KEY="your_public_key"
```

### Installation
```bash
# Install dependencies
npm install

# Generate Prisma client
npx prisma generate

# Apply database migrations
npx prisma db push

# Start development server
npm run dev
```

### Production Deployment
```bash
# Build the application
npm run build

# Start production server
npm start
```

## 🐛 Troubleshooting

### Common Issues

#### **Notifications Not Working**
1. Check browser permission settings
2. Verify VAPID keys are configured
3. Ensure service worker is registered
4. Check browser console for errors

#### **PWA Not Installing**
1. Ensure HTTPS connection (required for PWA)
2. Check manifest.json is accessible
3. Verify service worker registration
4. Try different browser

#### **Development Issues**
- PWA features disabled in development by default
- Use `sw-dev.js` for notification testing
- Check terminal logs for scheduler execution

### Debug Commands
```bash
# Check if service worker is registered
console.log(navigator.serviceWorker.controller);

# Test notification permission
console.log(Notification.permission);

# Manual notification test
new Notification("Test", { body: "Test message" });
```
